# 🎲 Random Number Generator (Dice Roller)

A functional web application that simulates dice rolls using PHP. This project demonstrates server-side logic, form handling, and cloud deployment.

## 🚀 Live Demo
[Click here to view the live app](https://random-number-generator-web-app-pi.vercel.app/)

## 🛠️ Features
- **Customizable Rolls:** User can specify the number of dice.
- **Multiple Dice Types:** Supports d4, d6, d8, d10, d12, and d20 via a dropdown menu.
- **PHP Logic:** Uses the `rand()` function for number generation.
- **Results Display:** Uses a `foreach` loop to display individual results and calculates a total sum.

## 💻 Tech Stack
- **Backend:** PHP 8.x
- **Frontend:** HTML5, CSS3
- **Deployment:** Vercel (using vercel-php runtime)
- **Local Dev:** XAMPP (Apache)

## 📂 Project Structure
- `/api/index.php`: Main application logic and UI.
- `vercel.json`: Deployment configuration for PHP on Vercel.
